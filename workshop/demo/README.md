# 백업 시연물 — 설치 없이 돌아갑니다

발표 현장에서 실제 시스템(사내망·계정·API 키)이 안 뜰 때를 대비한 대체본입니다.
둘 다 **인터넷·서버·계정 없이** 동작하고, 회사 자료는 하나도 들어 있지 않습니다.

## 1. `paste-to-table.html` — 엑셀 붙여넣기 → 지표 자동 인식 (시연 ①)

**더블클릭**만 하면 브라우저에서 열립니다.

1. `샘플 표 넣기` 버튼 → 머리글이 2줄로 쪼개진 표가 들어감
2. 머리글 ↔ 지표 매핑표와 "인식: 지표 7개 · 값 28개" 표시
3. 직접 엑셀에서 표를 복사해 붙여넣어도 동작 (탭·쉼표 구분 모두 인식)

실제 시스템의 판별 규칙(채권 종류 + 만기 조합)을 그대로 축약해 넣었습니다.

## 2. `make-docx.mjs` — 보고서 양식 워드 자동 생성 (시연 ②)

```
node make-docx.mjs
```
→ 같은 폴더에 `위험관리_보고서_양식샘플.docx` 생성.

- **외부 패키지 0개** — `npm install` 필요 없음 (Node 18 이상이면 어느 PC에서나)
- 바탕체 · A4 여백 상하 2.5cm/좌우 2cm · 줄간격 1.3 · 문단 기호 □ / - / * 3단
- 표 1개 포함

> 파일 구조는 검증했지만(문단 17개·표 4×3·여백 2.5/2.5/2.0/2.0cm 확인), **워드로 실제 열어 보는 확인은 한 번 해 주세요.**
> 글꼴이 없는 PC에서는 바탕체가 다른 글꼴로 대체될 수 있습니다.
