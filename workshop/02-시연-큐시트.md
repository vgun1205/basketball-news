# 02. 시연 큐시트 — 30~60초 영상 10편

> 각 편은 **결과부터 보여주고 과정을 설명**하는 순서입니다.
> 청중이 5초 안에 "무슨 화면인지" 알아야 하므로, 모든 편은 **자막 한 줄 + 결과 화면**으로 시작합니다.
> ★ 표시는 우선순위. 4편만 고른다면 ①②③④입니다.

## 공통 규칙

| 항목 | 기준 |
|---|---|
| 길이 | 30초(단순) / 45초(설명 필요) / 60초(라이브 코딩) |
| 화면 | 1920×1080, 브라우저 확대 125~150%, 터미널 글꼴 16pt 이상 |
| 소리 | 없음 (발표자가 직접 말함) — 대신 **자막 3~4장**을 굽습니다 |
| 커서 | 클릭 강조 켜기 (뒷줄에서 안 보임) |
| 배속 | AI 응답 대기 구간만 2배속 + `× 2배속` 자막. **속인 게 아니라는 걸 표시** |
| 첫 프레임 | 정지 상태에서도 무슨 화면인지 알도록 제목 자막을 0초부터 |

# ① 엑셀을 그대로 붙여넣으면 표가 스스로 정리된다 ★★★★★

**한 줄 훅** — "포털 화면 복사 → 붙여넣기 → 끝. 지표 이름은 프로그램이 알아서 맞춥니다."
**길이** 35초 · **화면** 브라우저(대시보드 '가져오기' 탭) · **AI 호출 없음 → 실패 위험 거의 0**

| 시각 | 화면 | 자막 |
|---|---|---|
| 0:00–0:05 | 평가사 엑셀 표를 드래그해 Ctrl+C | `매일 손으로 옮기던 표` |
| 0:05–0:12 | 가져오기 탭에 Ctrl+V (머리글이 2줄로 쪼개진 표 그대로) | `그대로 붙여넣기` |
| 0:12–0:20 | '미리보기' 클릭 → 머리글 ↔ 지표 매핑표가 뜬다 | `머리글을 읽고 지표를 스스로 판별` |
| 0:20–0:28 | "인식: 지표 7개 · 값 28개" 메시지 확대 | `7개 지표 · 28개 값` |
| 0:28–0:35 | '가져오기 실행' → 대시보드 전환, 값이 채워진 표 | `저장 완료 — 전일·전월·전분기·전년 비교 즉시 갱신` |

**말할 것** — "이게 왜 되냐면, 머리글이 두세 줄로 쪼개져 있어도 세로로 이어붙여서 '채권 종류 + 만기'를 찾아내게 해뒀기 때문입니다. 사람이 하던 눈치를 규칙으로 적어 준 것뿐입니다."

**Claude Code에서 어떻게 만들었나 (재현 프롬프트)**
```
평가사 포털 표를 그대로 복사해서 붙여넣으면 지표를 자동 인식하는 화면을 만들어줘.
머리글이 2~3줄로 쪼개져 오니까 열 단위로 세로로 이어붙여서 판단하고,
'채권 종류 + 만기' 조합으로 지표 코드를 맞춰줘. 저장 전에 매핑 미리보기를 보여줘.
```

**대비책** — 실제 시스템이 안 뜨면 `workshop/demo/paste-to-table.html` 을 더블클릭. 설치·인터넷 없이 같은 장면이 나옵니다.

# ② 내 보고서 양식이 그대로 나온다 ★★★★★

**한 줄 훅** — "글꼴·여백·줄간격·문단 기호까지, 내가 쓰던 양식 그대로 1초 만에."
**길이** 50초 · **화면** 터미널 + 워드 · **AI 호출 없음 → 실패 위험 거의 0**

| 시각 | 화면 | 자막 |
|---|---|---|
| 0:00–0:06 | 완성된 워드 문서를 먼저 보여줌(스크롤) | `사람이 만든 것처럼 보이는 이 문서` |
| 0:06–0:12 | 터미널로 전환, 명령 한 줄 입력 | `실제로는 명령 한 줄` |
| 0:12–0:18 | 실행 → `saved: 41KB` | `1초` |
| 0:18–0:34 | 워드로 열기 → 표지 / Summary / 본문 스크롤 | `표지 · 요약 · 본문 구성까지 고정` |
| 0:34–0:45 | 확대: □ 문단 / - 하위 / * 파란 보충문장, 콜론 뒤 줄맞춤 | `바탕체 · 여백 2.5/2cm · 줄간격 1.3` |
| 0:45–0:50 | 표 부분 확대 | `표·페이지번호까지 규칙대로` |

**말할 것** — "서식은 판단이 아니라 규칙입니다. 규칙은 한 번만 적어 두면 됩니다. 내용을 바꿔도 서식 지적이 다시 나올 일이 없습니다."

**명령**
```
node scripts/gen-tech-doc.mjs        # 기술·비용 정리 문서
node scripts/gen-manual.mjs          # 사용설명서
```

**Claude Code에서 어떻게 만들었나 (재현 프롬프트)**
```
첨부한 워드 파일과 똑같은 양식으로 문서를 만드는 스크립트를 짜줘.
바탕체, 여백 상하 2.5cm·좌우 2cm, 줄간격 1.3, 문단 기호는 □ / - / * 3단계,
'라벨 : 내용' 형태는 다음 줄이 콜론 뒤에 맞춰 정렬되게 해줘.
```

**대비책** — `node workshop/demo/make-docx.mjs` (외부 패키지 0개, 어느 PC에서나 실행)
※ 사내 문서를 화면에 띄우기 곤란하면 이 백업본으로 대체하는 편이 안전합니다.

# ③ 쌓인 자료에 말로 묻는다 ★★★★★

**한 줄 훅** — "검색이 아니라 질문. 답에는 근거 자료가 같이 옵니다."
**길이** 45초 · **화면** 브라우저(`/ask`) · **AI 호출 있음 → 사전 1회 예열 필수**

| 시각 | 화면 | 자막 |
|---|---|---|
| 0:00–0:06 | 질문 화면, 예시 질문 칩들 | `매일 자동으로 쌓인 감독·규제 자료` |
| 0:06–0:12 | 칩 클릭 → 질문 입력창에 문장이 들어감 | `"제3자 리스크, 무엇부터 챙겨야 하나?"` |
| 0:12–0:24 | 로딩 → 답변 생성 (×2배속) | `× 2배속` |
| 0:24–0:38 | 답변 스크롤 — 항목별 정리 | `자료를 근거로 정리된 답` |
| 0:38–0:45 | **출처 목록 확대**(기관·제목·날짜) | `어디서 나온 말인지 함께 표시` |

**말할 것** — "이게 일반 챗봇과 다른 점은 **우리가 쌓은 자료 안에서만** 답한다는 것, 그리고 출처를 붙인다는 것입니다. 근거 없는 문장이 보고서에 들어가는 게 제일 위험하니까요."

**Claude Code에서 어떻게 만들었나 (재현 프롬프트)**
```
아카이브에 쌓인 기사를 근거로 자연어 질문에 답하는 기능을 만들어줘.
검색은 키워드로 먼저 걸고, 임베딩 키가 있으면 의미검색을 더해줘.
키가 없어도 에러 없이 키워드만으로 동작해야 해. 답변에는 반드시 출처를 붙여줘.
```

**리스크** — 응답이 20초 넘게 걸리면 지루합니다. **촬영 직전에 같은 질문을 한 번 돌려** 캐시/연결을 예열하고, 편집에서 대기 구간을 2배속 처리하세요.

# ④ 말 한마디로 기능이 붙는다 — Claude Code 실황 ★★★★★

**한 줄 훅** — "요구사항을 말로 하면 화면이 바뀝니다. 요청서도 회의도 없이."
**길이** 60초 · **화면** 왼쪽 Claude Code 터미널 / 오른쪽 브라우저 (반반 배치)

**안전 버전(권장)** — 대상 파일: `workshop/demo/paste-to-table.html`

| 시각 | 화면 | 자막 |
|---|---|---|
| 0:00–0:08 | 오른쪽 브라우저: '국고채 2년' 열이 **인식 안 됨**(빨간 글씨) | `지금은 인식 못 하는 항목` |
| 0:08–0:16 | 왼쪽 터미널에 요청 문장 타이핑 | `말로 요청` |
| 0:16–0:34 | Claude가 파일을 찾아 수정안(diff)을 보여줌 (×2배속) | `× 2배속 — 고칠 부분을 스스로 찾음` |
| 0:34–0:42 | 변경 승인 | `승인` |
| 0:42–0:55 | 브라우저 새로고침 → '국고채 2년'이 **인식됨(초록 태그)** | `끝` |
| 0:55–1:00 | 바뀐 줄 확대 | `수정된 코드는 3줄` |

**입력할 문장**
```
workshop/demo/paste-to-table.html 에서 '국고채 2년'도 인식되게 해줘. 코드는 ktb2y로.
```

**실전 버전(자신 있으면)** — macro-monitor에서
```
아카이브 검색 기간 버튼에 '최근 3일'을 하나 더 추가해줘. 기존 버튼과 같은 방식으로.
```

**말할 것** — "여기서 중요한 건 제가 코드를 짠 게 아니라 **요구사항을 말했다**는 겁니다. 담당자가 원하는 항목 하나 늘리는 데 개발 요청서가 필요 없어집니다."

**안전장치** — 시연 전용 브랜치에서 촬영하고, 끝나면 `git checkout .` 로 되돌립니다.
**리스크** — 실시간 응답이 길어질 수 있음. **미리 한 번 돌려 보고**, 같은 요청을 다시 하면 훨씬 빠릅니다.

# ⑤ 파일 하나로 끝나는 오프라인 검색 ★★★★☆

**한 줄 훅** — "메일 첨부 파일 하나. 설치도 서버도 인터넷도 없이 검색됩니다."
**길이** 30초 · **화면** 메일 → 다운로드 → 브라우저

| 시각 | 화면 | 자막 |
|---|---|---|
| 0:00–0:06 | 메일 첨부 목록에서 `MI_아카이브_날짜.html` | `매일 메일에 붙어 오는 파일 하나` |
| 0:06–0:10 | **와이파이 끄기** 아이콘 클릭 | `인터넷 끄고` |
| 0:10–0:16 | 더블클릭 → 검색 화면이 그대로 뜸 | `그냥 열립니다` |
| 0:16–0:26 | 키워드 입력 → 기간 버튼(1주/1개월/올해) → 결과 | `키워드 · 기간 · 기관으로 검색` |
| 0:26–0:30 | 결과 이미지 캡처 버튼 | `캡처까지 파일 안에서` |

**말할 것** — "데이터와 검색 화면을 파일 하나에 같이 넣었습니다. 폐쇄망이거나 외부 서비스를 못 쓰는 환경에서도 배포가 됩니다. 보내는 방법이 메일 첨부라 별도 승인도 필요 없고요."

# ⑥ 사진 한 장이 데이터가 된다 ★★★★☆

**한 줄 훅** — "손으로 쓴 표를 찍어 올리면 항목이 알아서 채워집니다."

| 시각 | 화면 | 자막 |
|---|---|---|
| 0:00–0:07 | 손으로 쓴 기록지 사진 | `손으로 쓴 표` |

스케줄 설정 화면 → 실행 로그 → "키가 빠져도 에러가 아니라 기능만 줄어든다"는 코드 주석 한 줄 확대.
**말할 것** — "자동화의 진짜 난이도는 만드는 게 아니라 **한 달 뒤에도 조용히 돌아가게 하는 것**입니다. 그래서 실패를 전제로 짰습니다."

# ⑩ (예비) 폴더가 스스로 정리된다 · 30초

어질러진 폴더 → Claude Code에 "이 폴더 파일들 내용 보고 종류별로 폴더 만들어 정리해줘" → 정리된 결과.
**말할 것** — "업무 파일도 같습니다. 점검 증빙, 회의 자료, 캡처 이미지 — 이름만 봐서는 못 찾던 것들이 정리됩니다."
