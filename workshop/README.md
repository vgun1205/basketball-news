## 결론부터

- 이번 발표에서 보여준 "위험관리 MI"는 **기능 8개가 붙은 묶음**이고, 쓴 건 '메일 발송' 하나뿐입니다.
- 남은 것 중 **엑셀 자동 인식 · 워드 양식 자동 생성 · 자료에 말로 묻기** 셋이 공감도가 가장 높습니다.
- 여기에 **말 한마디로 기능이 붙는 라이브 시연** 한 편을 더하면, "저 사람이니까 되는 것"이라는 인상이 깨집니다.
