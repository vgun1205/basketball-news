# 03. 발표 구성 · 촬영 · 예상 질문

## 1. 기존 발표자료에 어떻게 끼워 넣나

지금 발표자료는 **BCM 시뮬레이터**와 **위험관리 MI 뉴스** 두 개가 기둥입니다.
이 둘은 "완성된 시스템"이라 청중이 **"저건 잘하는 사람이니까 되는 것"** 으로 받아들이기 쉽습니다.
새로 넣을 부분의 역할은 그 인식을 깨는 것 — **"작고, 오늘 당장, 나도"** 입니다.

```
[기존] 도입 배경 → BCM 시뮬레이터 → 위험관리 MI 뉴스
                                        ↓ 여기에 삽입
[신규] "그런데 이런 것도 됩니다" (30~60초 영상 4~6편)
          ①엑셀 붙여넣기  ②워드 양식  ③말로 묻기  ④말로 고치기  ⑤파일 하나  ⑥사진→데이터
                                        ↓
[신규] "공통점" 한 장 — 다 같은 방식으로 만들었다
                                        ↓
[기존/보강] 그래서 무엇부터 하면 되나 (마무리)
```

## 2. 새로 넣을 장표 구성안 (7장)

| # | 제목 | 내용 |
|---|---|---|
| 1 | 그런데, 이런 것도 됩니다 | 전환 장표. 앞의 두 시스템은 "몇 달 걸린 것", 지금부터는 "며칠·몇 시간짜리" |
| 2 | 엑셀을 그대로 붙여넣으면 | 영상 ① + 한 줄: *사람이 하던 눈치를 규칙으로 적어 준 것* |
| 3 | 내 보고서 양식 그대로 | 영상 ② + 한 줄: *서식은 판단이 아니라 규칙* |
| 4 | 쌓인 자료에 말로 묻기 | 영상 ③ + 한 줄: *검색이 아니라 질문 — 답에 근거가 붙는다* |
| 5 | 말 한마디로 기능이 붙는다 | 영상 ④ + 한 줄: *요구사항을 말하면 화면이 바뀐다* |
| 6 | (선택) 사진 한 장이 데이터로 / 파일 하나로 검색 | 영상 ⑥ 또는 ⑤ |
| 7 | 공통점 — 다 같은 방식 | 아래 3줄. **이 장이 발표의 핵심 메시지** |

### 7번 장표에 들어갈 3줄

1. **어려운 걸 만든 게 아니라, 반복되는 걸 없앴다** — 붙여넣기, 서식 맞추기, 자료 찾기, 옮겨 적기
2. **말로 시작해서 말로 고쳤다** — 기획서·요청서·회의 없이, 쓰면서 고침
3. **실패를 전제로 짰다** — 키가 없으면 에러가 아니라 기능만 줄어들고, 다음날 다시 시도

## 3. 촬영·편집 실무

**녹화** — Windows `Win + Alt + R`(Xbox Game Bar) 또는 OBS. 화면 1920×1080 고정.
사내 PC에서 녹화 도구 설치가 막혀 있으면 **PowerPoint 자체의 '화면 녹화'** 기능(삽입 → 화면 녹화)으로 충분합니다.

**편집** — 자를 것만 자릅니다. 필요한 작업은 세 가지뿐:
1. 앞뒤 잘라내기
2. AI 대기 구간 2배속 (+ `× 2배속` 자막)
3. 자막 3~4장 얹기 (큐시트의 자막 열 그대로)

**슬라이드에 넣기** — 영상 파일을 삽입 → 애니메이션 탭에서 **'자동 실행' + '반복 재생'**.
발표 중 재생 버튼을 찾느라 흐름이 끊기는 게 제일 흔한 사고입니다.

**백업** — 모든 영상은 **마지막 프레임을 이미지로 따로 저장**해 두세요.
영상이 안 돌아가면 그 이미지 한 장으로 설명할 수 있습니다.

## 4. 예상 질문과 답

| 질문 | 답 |
|---|---|
| "코딩 할 줄 알아야 되는 거 아닌가요?" | 영상 ④가 답입니다. 제가 한 건 요구사항을 문장으로 말한 것이고, 파일을 찾아 고친 건 도구입니다. |
| "비용이 얼마나 드나요?" | 질문할 때만 발생합니다. 안 쓰면 0원. 실제 사용량 기준 월 1만 원대이고, 장비·상용 소프트웨어 구입은 없습니다. |
| "사내 자료를 넣어도 되나요?" | **안 넣습니다.** 지금 만든 것들은 공개 시장데이터·공개 보도자료만 씁니다. 내부 자료를 쓰려면 별도 검토가 필요하고, 그 전까지는 이 선을 지킵니다. |
| "폐쇄망에서도 되나요?" | 영상 ⑤가 부분적인 답입니다. 파일 한 개로 배포되는 형태는 그대로 되고, 자동 수집은 외부 연결이 필요합니다. |
| "AI가 틀린 말을 하면요?" | 그래서 답변에 **출처를 붙였습니다**(영상 ③). 자동 생성물은 초안이고, 최종 책임은 작성자에게 있다는 걸 문서에도 명시해 뒀습니다. |
| "얼마나 걸렸나요?" | 시스템 두 개는 몇 달, 오늘 보여드린 것들은 대부분 **하루 이내**입니다. 시작이 무거우면 안 하게 되니까 작게 시작하는 게 요령입니다. |

## 5. 마무리 장표 제안 — "무엇부터 하면 되나"

청중이 자리에서 일어나 할 수 있는 크기로 세 개만.

1. **매주 똑같이 만드는 문서 한 개**를 고른다 → 서식부터 자동화 (영상 ②)
2. **손으로 옮겨 적는 표 한 개**를 고른다 → 붙여넣기 자동 인식 (영상 ①)
3. **매일 찾아보는 자료 한 곳**을 고른다 → 자동 수집 + 검색 (영상 ③⑤)

> "세 개 다 하실 필요 없습니다. **하나만** 고르시고, 그걸 말로 설명하는 것부터 시작하시면 됩니다."
