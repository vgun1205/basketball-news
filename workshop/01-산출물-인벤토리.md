# 01. 산출물 전수 리뷰 — 시연 소재 인벤토리

> 검토 범위: GitHub 저장소 5개 전체 소스 + Claude 세션 목록 15건(제목·저장소·기간).
> 다른 PC에서 돌아간 세션의 **대화 원문은 이 환경에서 열람할 수 없어**, 세션은 제목·연결 저장소로만 분류하고
> 시연 소재는 **실제 코드로 확인된 기능**만 올렸습니다.

---

## 요약 — 시연 후보는 어디에 있나

| 저장소 | 성격 | 시연 소재 | 이번 발표 사용 |
|---|---|---|---|
| `macro-monitor` | 위험관리 MI + 거시지표 모니터 | **12건** (최다) | 뉴스 발송 부분만 이미 사용 |
| `bcm-training` | BCM 실시간 도상훈련 | 6건 | 이미 사용 → 제외 |
| `basketball-tracker` | 사진 → 기록 자동 추출 웹앱 | 3건 | 미사용 ★ |
| `basketball-news` | 뉴스 자동발송(개인판, EWI와 동일 구조) | 3건 | 미사용 |
| `family-calendar` | 실시간 동기화 PWA | 2건 | 미사용 |

**핵심 발견**: "위험관리 MI"는 *뉴스 메일 한 개*가 아니라 **8개 기능이 붙어 있는 묶음**입니다.
이번에 발표에서 보여준 건 그중 '메일 발송' 하나뿐이고, **나머지 7개가 아직 안 쓰인 시연 소재**입니다.

## A. macro-monitor — 위험관리 MI / 거시지표 모니터

이번 시연 소재의 8할이 여기 있습니다. 기능별로 쪼개 봅니다.

| # | 기능 | 어디에 | 시연가치 | 비고 |
|---|---|---|---|---|
| A1 | **엑셀 붙여넣기 → 지표 자동 인식** | `MacroDashboard.jsx` 가져오기 탭 | ★★★★★ | 머리글이 2~3줄로 쪼개져 있어도 세로로 이어붙여 판독 |
| A2 | **회사 보고서 양식 그대로 워드 생성** | `lib/issuedoc.js` | ★★★★★ | 표지→Summary 국내→Summary 해외→본문(Ⅰ,Ⅱ…). 바탕체·여백 2.5/2cm·줄간격 1.3까지 코드 |
| A3 | **쌓인 자료에 자연어로 질문 (RAG)** | `lib/rag.js`, `/ask` | ★★★★★ | 키워드+의미검색 하이브리드, 답변 합성은 Sonnet·질의확장은 Haiku, **출처 표시** |
| A4 | **파일 하나로 끝나는 오프라인 아카이브** | `lib/archivehtml.js` | ★★★★☆ | 데이터+검색UI+캡처 라이브러리를 HTML 한 파일에 내장 → 폐쇄망에서도 동작 |
| A5 | **주간 AI 브리핑 자동 작성** | `lib/briefing.js`, `/briefing` | ★★★★☆ | 최근 N일 기사를 읽고 팀 관점 핵심 이슈·유의사항 도출, 주차별 히스토리 |
| A6 | 기준일 대비 전일·전월·전분기·전년 자동 비교 | `MacroDashboard.jsx`, `lib/report.js` | ★★★★☆ | "기준일 시점의 최신 가용 데이터"를 지표별로 따로 계산 |
| A7 | 영문 기사 자동 번역·1문장 요약 | `lib/translate.js`, `lib/global.js` | ★★★☆☆ | 해외 보험 전문매체 RSS → 본문 추출 → 한글 제목·요약 |
| A8 | 메일에 xlsx·PDF·워드·아카이브 자동 첨부 | `lib/mail.js`(543줄) | ★★★☆☆ | 금감원 보도자료 **원문 PDF까지** 끌어와 첨부 |
| A9 | 바꾸기 전에 영향 측정(A/B 시뮬레이션) | `scripts/sim-queries.mjs` | ★★★★☆ | 검색어 세트·상한값을 바꾸면 메일 구성이 어떻게 달라지는지 **발송 없이** 측정 |
| A10 | 매뉴얼·기술/비용 문서 자동 생성 | `scripts/gen-manual.mjs`, `gen-tech-doc.mjs` | ★★★★☆ | 문서도 코드로 관리 → 내용 바뀌면 재실행 |
| A11 | 카톡 '나에게 보내기' 요약 | `lib/kakao.js`, `lib/summary.js` | ★★☆☆☆ | 200자 초과 시 증감을 빼고 레벨만 — 절대 중간에서 안 잘림 |
| A12 | 무인 운영 + 우아한 축소 | `vercel.json`, `.github/workflows` | ★★★☆☆ | 키가 없으면 **에러가 아니라 기능만 축소**되게 설계 |

**수집 경로**: 금감원·금융위·손해보험협회 게시판 크롤 + 네이버 뉴스 API + 구글 뉴스 RSS + 해외 전문매체 RSS.
주요 매체 가중치(`major`), 중복 제거, 기관 자료 우선 정렬까지 들어 있습니다(`lib/news.js` 796줄).

## B. bcm-training — BCM 실시간 도상훈련 *(이번 발표에서 이미 사용 → 제외)*

제외 대상이지만, 발표 중 "같은 방식으로 이런 것도 됩니다" 근거로 한 줄씩 인용할 만한 것들:

- 외부 패키지 **0개**로 만든 실시간 훈련 서버 (설치 없이 어디서든 구동)
- 시나리오 8종(랜섬웨어/DC 화재/보안패치/DDoS/정보유출/클라우드 장애/지진/핵심인력 부재)
- 역할별 🔒 **전용 정보** 실시간 전달 → 정보 비대칭 훈련
- **엑셀 마스터 → 코드 자동 변환**(`convert_master.py`) — 시나리오를 엑셀에서 고치면 훈련에 반영
- 훈련 종료 시 **증적 보고서** 다운로드
- 임원 개인 폰 참여용 터널 + 4자리 입장 코드

## D. basketball-news — 개인판 뉴스 자동발송 *(EWI 모니터와 동일 구조)*

- **증분 발송** — 한 번 보낸 기사는 다시 안 보냄(`data/seen.json`, 30일 자동 정리)
- **주간 키워드 주기** — 어떤 키워드는 7일에 한 번만(`data/weekly.json`), 수집 실패한 날은 주기를 소진하지 않음
- **토큰 암호화 보관** — 공개 저장소에 카톡 리프레시 토큰을 못 두니 AES-256-GCM으로 암호화(`lib/stateCrypto.js`)
- **부팅 직후 발송 실패 대응** — 절전 복귀 직후 SMTP DNS가 아직 안 붙는 게 아침 실패의 진짜 원인이었고, 연결될 때까지 대기하도록 처리(`lib/net.js`)

> 발표 스토리로 좋은 지점: **개인 취미 프로젝트에서 검증한 구조를 회사 EWI 모니터에 그대로 이식**했다는 점.

- 한 폰에서 고치면 다른 폰에 즉시 반영, 반복 일정, 구글 캘린더 양방향, ICS 구독, 홈화면 앱 설치
